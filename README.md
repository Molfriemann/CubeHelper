## 主要功能

### 用户系统
- **管理员（admin）**：首次启动无密码，可自行设定密码；负责创建、修改、注销普通用户。
- **普通用户**：由管理员创建，支持独立密码或免密登录；可自行修改密码、注销账号（数据永久删除）。
- 每个用户成绩数据独立存储为 `Users/<用户名>.json`，互不干扰。

### 项目与标签管理
- 手动创建项目，自定义标签。
- 从 `Events` 目录下的预设文件一键导入项目（如“三阶魔方”）。
- 预设项目的标签不可删除，自定义标签可自由增删。

### 成绩录入
- **单条录入**：输入秒数或时/分/秒，可标记为 DNF（无效成绩），附带备注和标签。
- **批处理**：一次性录入多条成绩，共用标签和备注。
- **比赛模式（五次取平均）**：固定录入 5 次，每次可设为 DNF；自动计算去头尾平均（≥2 个 DNF 则整批记为 DNF）。
- 每条记录自动分配唯一 ID（单条为数字，批处理为 `X-Y`），记录录入时间。

### 成绩查看与操作
- 按项目查看成绩，支持**单次**和**平均**（比赛模式）两种视图。
- 单次视图：显示所有单条及批处理成绩，可切换按时间或按成绩排序。
- 平均视图（仅三阶魔方等支持比赛模式的项目）：显示每次比赛的平均成绩，可切换排序。
- 支持修改成绩（时间、备注）、删除成绩（批处理或比赛模式会整批删除）。
- DNF 成绩在表格中显示为 `#DNF`。

### 成绩报告（待界面完善）
- 基于最近有效成绩生成折线图和趋势线。
- 计算全部数据及修剪后（去掉最好 3%、最差 5%）的统计量。
- 对于预设项目（如三阶魔方），依据修剪后平均成绩进行段位评定（A1~E4），并显示评语。

### 预设扩展系统
- 将 `.py` 文件放入 `Events/` 文件夹，只要定义了继承自 `Project` 的类并以 `ProjectClass` 导出，程序启动时自动识别并加入预设列表。
- 预设文件可自定义录入模式、段位评定逻辑等，无需修改主程序。

### 路径自校验
- 通过 `check.bin` 确保项目路径未被移动，防止数据文件错乱。

## 运行环境与依赖

- **Python** 3.8 及以上
- **依赖库**：
  - `numpy`（用于统计计算）
  - `matplotlib`（用于图表绘制）

安装依赖：
pip install numpy matplotlib
快速开始
下载或克隆整个 CubeHelper 文件夹。

打开终端，进入 CubeHelper 目录。

运行 python main.py。

首次启动将自动生成必要文件，并弹出登录窗口。

选择 admin（无需密码）登录，进入管理员界面。

在管理员界面中创建普通用户（可选设密码）。

退出并重新登录为普通用户，即可开始管理魔方成绩。

如果要使用预设项目（如三阶魔方），确保 Events/cube_3x3x3.py 文件存在，启动时程序会自动识别。

注意事项
管理员账户不可注销、不可删除。

普通用户注销会永久删除其所有数据文件，无法恢复。

预设项目的标签无法从界面删除，如需修改请编辑对应的 Events/*.py 文件并重新启动程序。

请勿手动编辑 Users/<用户名>.json 或 check.bin 等数据文件，以免损坏。

如果移动了整个项目文件夹，请删除 check.bin，程序会在下次启动时重新生成。

成绩报告依赖 numpy 和 matplotlib，请确保已正确安装。

常见问题
1. 启动报错 IndentationError 或 AttributeError？
请检查从仓库获取的文件是否完整，确保没有手动修改导致缩进错误。本项目的所有 .py 文件均使用4 个空格缩进。

2. 无法登录管理员账号？
如果是首次运行，管理员默认免密，直接选择 admin 并点击登录即可。如果之前已设密码但忘记，可打开 Users/admin.json 手动修改 require_password 为 false，重启程序。

3. 预设项目没有出现？
确认 Events/ 文件夹下存在有效的 .py 文件（如 cube_3x3x3.py），且文件中定义了 ProjectClass。

重启程序，程序会自动扫描并更新 event_list.json。

4. 窗口组件显示不全或布局错乱？
本程序设计支持 1050x750 以上的分辨率，如果屏幕较小可适当调整窗口大小，或修改 main.py 中的 root.geometry 参数。

开发与贡献
本项目采用模块化设计，便于扩展：

新增预设项目：在 Events/ 下添加继承 project_base.Project 的类，并导出为 ProjectClass。

新增录入模式：在预设类中重写 get_input_modes() 方法。

界面优化：main.py 中的各个选项卡可进一步拆分为独立视图文件。
